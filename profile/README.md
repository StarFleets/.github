# StarFleets 🖖

StarFleets is a Star Trek fan community: a fleet of members who hold ranks, serve on ships, play together and keep a shared home on the web. We build the software that runs it, in the open where we can.

This is a fan project. It is not affiliated with or endorsed by any rights holder of Star Trek.

## 🌐 Home

[starfleets.net](https://starfleets.net)

## 📦 Public repositories

- [go-startrek-date](https://github.com/StarFleets/go-startrek-date): the StarFleets official stardate as a small Go package (Apache-2.0).
